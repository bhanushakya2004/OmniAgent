# OmniMission API

FastAPI backend service powering OmniMission AI:
- Layered architecture: Router → Service → Repository → DB.
- Agno 3.1.3 Multi-Agent Mission Engine with Google Gemini models.
- Hybrid Search with PostgreSQL pgvector and Reciprocal Rank Fusion (RRF).
- Ports and Adapters architecture for GCP drop-in readiness.
