# ADR 0017: Merchant Store Analyst Console and Recharts Visualization

## Status
Accepted

## Context
Physical retail store managers require rapid, visual situational awareness without learning SQL query syntax. They need to understand:
1. **Daily Operational Health:** Immediate visibility into stockouts, minimum reorder breaches, daily revenue, and pending restock tasks upon opening the management portal.
2. **Conversational Inquiries with Instant Visuals:** The ability to ask ad-hoc questions ("Which items have high stockout risk?", "What are our top selling products by revenue?") and immediately receive chart-ready visualizations rather than raw JSON or static text tables.
3. **Auditability & Trust (Glass-Box AI):** Store managers must be able to inspect the exact SQL query generated by the AI agent to verify how numbers were calculated.
4. **Governed Execution:** When the AI discovers that stock is depleted, managers need one-click Human-in-the-Loop authorization to trigger immediate replenishment work orders without manual data entry.

## Decision
1. **Interactive Store Analyst AI Console (`StoreAnalystConsole`):**
   - Built a dedicated console in `apps/web/src/components/merchant/store-analyst-console.tsx` mounted prominently in the `/merchant` operations portal.
   - Features a natural language query interface with pre-canned suggestion chips for high-frequency queries.

2. **Proactive Morning Briefing:**
   - Automatically renders the daily briefing banner summarizing store revenue, active stockouts, low-stock SKUs, and pending proposals.

3. **Dynamic Recharts Visualization:**
   - Inspects `chart_config.chart_type` returned by the backend:
     - `bar`: Renders `BarChart` with custom rounded bars and tooltips for ranking and categorical comparisons.
     - `line`: Renders `LineChart` with time-series curves for multi-day revenue trends.
     - `pie`: Renders `PieChart` with department distribution slices.
     - `table`: Renders tabular data for multi-attribute listings.
   - Includes a collapsible "View SQL" code view displaying the AST-sanitized PostgreSQL query validated by `SqlGuard`.

4. **Human-in-the-Loop Proposal Actions:**
   - Renders live action proposals drafted by the agent.
   - Provides immediate `[Approve & Execute]` and `[Reject]` actions that call `/api/v1/merchant/proposals/{id}/approve` and mutate inventory or create restock tasks in real time.

## Consequences
- **Rapid Operational Decisions:** Store managers identify and resolve stockout risks in seconds.
- **Auditable AI Intelligence:** Zero ambiguity about metrics calculation thanks to inspectable SQL queries.
- **Empowered Human Supervision:** Real-world inventory replenishments remain strictly governed by store manager sign-off.
